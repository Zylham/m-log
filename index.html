Cadangan data

Data tersimpan otomatis di perangkat ini. Unduh cadangan secara berkala, atau gunakan fitur ini untuk memindahkan data ke perangkat lain.

Pemasangan

iPhone dan iPad: buka di Safari, ketuk Bagikan, lalu Tambah ke Layar Utama.

Android: buka di Chrome, ketuk menu titik tiga, lalu Instal aplikasi.

Laptop dan PC: di Chrome atau Edge, klik ikon instal di kolom alamat, atau menu titik tiga lalu Instal.

Data: tersimpan di perangkat masing-masing, jadi tiap perangkat punya data sendiri. Jangan hapus data browser, dan gunakan tombol cadangan.
